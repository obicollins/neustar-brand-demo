# Neustar — brand website demonstration

Portfolio demonstration of a Next.js, React and TypeScript technology company website built by Tobey Collins. Includes eight service pages, company and contact pages, and three original editorial articles.

The repository root contains a static GitHub Pages demonstration at /neustar-brand-demo/. A readable copy of the authored application is in source/. The demo uses tiny static navigation, video and sharing helpers; business form delivery is disabled.

Original brand website: https://neustar.com.ng/

GitHub Pages: https://obicollins.github.io/neustar-brand-demo/

## Deployment

Publish the repository root using GitHub Pages. All demo asset and page paths are rebased to this repository slug. The .nojekyll file preserves underscore asset directories.

The original source is an export-mode Next.js project. The website is pre-rendered HTML, with local fonts, optimized images and a deferred silent hero film. No server credentials, customer data or private files are included.
